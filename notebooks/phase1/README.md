# Phase 1 — Exploratory Data Analysis

This folder contains the notebooks developed during Phase 1 of the SunHoldings Databricks project.

## Notebooks

- `01. DataUnderstanding`: Initial understanding of the source datasets.
- `02. Employee_EDA`: Exploratory analysis of employee-related patterns.
- `03. Location_EDA`: Exploratory analysis by location.
- `04. Time_EDA`: Temporal patterns and transaction timing.
- `05. Fraud_EDA`: Exploratory analysis of potential transaction anomalies.
